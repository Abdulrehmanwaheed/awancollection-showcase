## Project overview

Awan Collection is a client e-commerce website built to provide a streamlined online shopping experience. The project covers the customer-facing storefront and the supporting application architecture for catalog management, shopping cart, checkout, and order administration.

This is a **public portfolio case study**. The production application's source code is maintained in a separate **private repository** to respect client confidentiality and protect implementation details.

## Key features

- **Responsive storefront** — mobile-friendly layouts and product discovery
- **Product catalog** — category filtering, product details, images, and specifications
- **Shopping cart** — quantity management, persistent cart state, and shipping calculations
- **Checkout experience** — customer details, shipping options, and cash-on-delivery flow
- **Order management** — confirmation screens, order statuses, and admin workflows
- **WhatsApp integration** — convenient product inquiries and order follow-up links
- **Configurable architecture** — reusable brand, shipping, and payment configuration

*Features reflect the project's documented application implementation; availability on the live website can vary by deployment configuration.*
